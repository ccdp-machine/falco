📱 Read Aloud bookmarklet

Chrome on iPhone doesn't support browser extensions, so there's no way to install a screen-reader add-on the usual way. A bookmarklet — a bookmark whose address is a snippet of JavaScript instead of a URL — sidesteps that: tapping it injects the reader into whatever page you're already on.

2. Install it in Chrome on iPhone

  1. Copy the code above (tap "Copy bookmarklet").
  2. Bookmark any page: tap Share → Add Bookmark.
  3. Open Bookmarks (the ☆ / list icon), then tap Edit on the new bookmark.
  4. Rename it "Read Aloud" and replace its address with the code you copied, then save.
  5. On any page you want read aloud: tap the address bar, type Read Aloud, and tap it.

A floating toolbar appears at the bottom of the page with play/pause/stop, previous/next element, previous/next heading, and speed controls. Tap the bookmark again to remove it.
